# ROMs

`DFS-1770-2.20.rom` is the ACP (Pres) Advanced 1770 DFS for the Acorn
Electron's Plus 3 disc interface, the filing system the game is run with
(16,384 bytes, SHA-1 `c62f1290f689788dad6a2df30ace083eb827cffe`). It is
copyright its authors, and is included here only so that the disc can be
run in emulators and by the web player without hunting for it.

The Electron's MOS and BASIC ROMs are not included; emulators carry their
own, and they can be had from, for example, hoglet67's
[ElectronFpga](https://github.com/hoglet67/ElectronFpga) repository.
